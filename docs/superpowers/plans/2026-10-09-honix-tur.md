# Tur Honix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tur sorot menu navigasi bareng Honix — otomatis sekali, tawaran tiap 30 hari, bisa diputar dari Pengaturan.

**Architecture:** Logika murni (langkah + keputusan jadwal) di `src/lib/honix-tur.ts`, state di store `honix-setelan` yang udah ada (`profiles.honix_settings.tur`). UI = host yang dipasang di `NavRail`, render overlay/tawaran lewat portal ke `document.body`; target dicari lewat `data-tur` di item nav.

**Tech Stack:** Next 16 (App Router, client components), React 19, Supabase, node:test.

**Spec:** `docs/superpowers/specs/2026-10-09-honix-tur-design.md`

## Global Constraints
- `src/app/page.tsx` (Beranda) dan halaman lain TIDAK diubah.
- Tanpa migration — field `tur` di jsonb `honix_settings`.
- Token & kelas Honix yang ada (`.hx`, `hx-btn-*`, `--hx-*`, `--dur-*`, `--ease-out-*`); jangan bikin warna baru.
- Target sentuh ≥44px; hover ikut `:focus-visible`; `kurangiGerak` mematikan animasi.
- Interval tawaran = 30 hari.

## Review Focus
- Setelan akun belum kebaca → tur jangan keburu muncul (keputusan nunggu `siap`).
- `terakhir` berisi string rusak → perlakukan sebagai belum pernah (tur jalan), jangan crash.
- Target nav tersembunyi (rail `display:none` di HP) → pilih elemen yang kelihatan; langkah tanpa target dilewati.
- Resize/rotasi saat tur jalan → lubang & balon ikut pindah.
- Navigasi lewat CTA terakhir → `terakhir` tercatat sebelum pindah halaman.
